Board-Manager nicht erreichbar Der Board-Manager benötigt Autodarts 2.1 oder neuer. Alternativ kannst du das Board über die Terminal-Einrichtung konfigurieren.
💡 So richtest du dein Board ein: Der Board-Manager öffnet sich in einem neuen Tab. Dort meldest du das Board an deinem Autodarts-Konto an, ordnest die Kameras zu, passt Auflösung und Bildeinstellungen an und kalibrierst das Board. Danach einfach auf play.autodarts.com spielen.

⚡ Neustart & Herunterfahren

Dienst- und Systemneustart sowie das sichere Herunterfahren des Endgeräts.

⚠️ Wichtig: Stromversorgung nicht vorher trennen! Endgerät immer zuerst über „Herunterfahren“ ausschalten. Warte auf die Meldung „System ist aus“.

Admin / Netzwerkverwaltung

Hier kannst du Netzwerk-Einstellungen ändern, WLAN scannen, verbinden und den Hotspot starten.

⚠ Wichtig: Beim Starten des Hotspots wird das LAN-Netzwerk vorübergehend unterbrochen. Das Endgerät wechselt dann auf das Hotspot-Subnetz 192.168.4.1/24.

Terminal-Einrichtung (Fallback)

Autodarts neu starten?

Autodarts wird neu gestartet. Das System selbst wird nicht neu gestartet.

🔄 System neu starten?

Das System wird neu gestartet. Autodarts startet danach automatisch wieder.

❌ System herunterfahren?

Das System wird sicher heruntergefahren. Danach kann die Stromversorgung ausgeschaltet werden.

System wird neu gestartet …

Bitte warten. Das System startet jetzt neu.

System wird heruntergefahren …

Bitte warten. Das System wird jetzt sicher ausgeschaltet.

System ist aus

Das System wurde sicher heruntergefahren.

Die Stromversorgung kann jetzt ausgeschaltet werden.
